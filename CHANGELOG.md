# Changelog

## 0.0.1 - Initial Windows release

- Packaged the React dashboard and Spring Boot backend into one installer.
- Bundled a 64-bit Java runtime; Java is not required on the recipient's PC.
- Added automatic Windows service installation and startup.
- Added desktop and Start Menu shortcuts.
- Added local H2 persistence for application history and SMTP settings.
- Added Excel contact import, resume upload, templates, SMTP testing, and campaign controls.
